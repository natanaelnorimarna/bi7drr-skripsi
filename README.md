# bi7drr-skripsi

# Analisis BI-7Day Reverse Repo Rate

Repositori ini berisi kode analisa BI7DRR untuk memodelkan suku bunga CIR untuk skripsi "Optimisasi Portofolio Asuransi Bagi Keluarga Muda Dengan Satu Anak Menggunakan Weighted Goal Programming", IPB University

## Sumber Data
- Data: BI-7Day-Repo Rate
- Sumber: Bank Indonesia, https://www.bi.go.id/id/statistik/indikator/bi-rate.aspx
- Tanggal akses: 28 September 2026
- Periode data: 16 Juni 2026 s.d. 20 Mei 2026
- Hak cipta data tetap pada Bank Indonesia.

## Cara Menjalankan
    pip install pandas numpy matplotlib
    python src/Model Suku Bunga CIR.py
